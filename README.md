# 🧮 Modern Glassmorphism Calculator

A sleek and responsive calculator built using HTML, CSS, and JavaScript.
It features a modern glassmorphism UI with smooth animations and real-time arithmetic functionality.

# ✨ Features
🎨 Glassmorphism design with blur effects
🌈 Gradient background styling
📱 Fully responsive layout
⚡ Real-time calculations using JavaScript
🖱️ Smooth hover and click animations
➕ Basic arithmetic operations (+, −, ×, ÷)
🧹 One-click clear function
🔢 Clean and user-friendly interface

🚀 Demo
You can run the project by simply opening the index.html file in your browser.

# 🛠️ Tech Stack
HTML5
CSS3 (Glassmorphism, Flexbox, Grid)
JavaScript (DOM Manipulation, Event Handling)

# ⚙️ How It Works
Button clicks are captured using onclick events
Input values are appended to the display dynamically
eval() is used to compute expressions
Clear button resets the display
Error handling is included for invalid expressions
